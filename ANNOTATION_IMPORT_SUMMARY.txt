STEP 3: Verify

================================================================================
SUPPORTED FORMATS
================================================================================

1. JSON (Single Task)
   Command:  --format json --file file.json --task-id 243 --project-id 42
   Format:   Array of annotation objects
   Example:  example_annotations.json

2. JSON (Per-Task)
   Command:  --format json-per-task --file file.json --project-id 42
   Format:   Object with task IDs as keys
   Example:  example_annotations_per_task.json

3. CSV
   Command:  --format csv --file file.csv --task-id 243 --project-id 42
   Format:   Spreadsheet with columns: type, label, x, y, width, height, text, color
   Example:  example_annotations.csv

4. COCO
   Command:  --format coco --file coco.json --project-id 42
   Format:   COCO JSON with images, annotations, categories
   Docs:     https://cocodataset.org/

5. YOLO
   Command:  --format yolo --dir labels/ --project-id 42
   Format:   Directory of .txt files (one per image)
   Content:  class_id center_x center_y width height (normalized 0-1)

================================================================================
ANNOTATION TYPES

Comment:
  {"type": "comment", "text": "Important", "x": 200, "y": 300}

================================================================================
CONVERSION EXAMPLES
================================================================================

If you have COCO data, convert to JSON first:
  python convert_formats.py --from coco --input coco.json --output data.json

If you have YOLO data, convert to JSON first:
  python convert_formats.py --from yolo --input labels/ --output data.json --image-width 1280 --image-height 720

If you want to convert JSON to CSV for editing:
  python convert_formats.py --from json --to csv --input data.json --output data.csv

================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: "Task not found"
  └─ Solution: Verify task exists with correct ID and project ID

Issue: "Invalid JSON"
  └─ Solution: Validate with: python -m json.tool file.json

Issue: Annotations don't appear after import
  └─ Solution: Refresh browser (Ctrl+Shift+R), check import output says "✓ Imported: X"

Issue: Wrong labels or colors
  └─ Solution: Labels are case-insensitive, colors are optional (auto-assigned if omitted)

Issue: "Database connection failed"
  └─ Solution: Verify .env has correct DATABASE_URL and PostgreSQL is running
